Verified Project Facts (from source code)
What WasteWise actually does — confirmed from code 1. User uploads a waste image (JPG/PNG/WEBP) via a browser UI built in plain HTML + CSS + Vanilla JS.
2. The image is sent via HTTP POST (FormData) to a Flask backend at /analyze.
3. Flask saves the image, base64-encodes it, and sends it to Moondream running locally via Ollama at localhost:11434.
4. Two targeted questions are asked: (Q1) "What type of waste or recyclable object is this? Name the object and material." (Q2) "What material is the main object made of? One or two words only."
5. Both text answers are concatenated. A Python keyword-matcher maps the combined text to one of 15 structured waste profiles (plastic bottle, glass, metal can, paper, electronic, battery, food, textile, styrofoam, light bulb, aerosol, rubber, wood, medicine, ceramic).
6. If nothing matches, a DEFAULT profile ("Unidentified Waste Item") is returned with a 62% confidence score. Matched items return 91% confidence.
7. The result JSON contains: name, description, confidence, category, material, materialFull, materialsDescription, materials[], recovery[], uses[], disposalTitle, disposalText, safety, environment.
8. The frontend renders this into 5 tabs: Overview, Materials, Recovery, Possible Uses, Disposal.
9. The UI includes a 4-step animated progress bar (Image received → Identifying waste → Analyzing materials → Generating guidance) that runs while the AI call is in progress.
10. Users can drag-and-drop or click to upload. "Scan Another Item" resets the entire flow.
