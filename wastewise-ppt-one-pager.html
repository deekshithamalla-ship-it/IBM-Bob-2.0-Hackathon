Slide 1 — Project Overview

What is WasteWise?

WasteWise is an AI-powered web application that identifies waste items from a photo and instantly provides detailed guidance on materials, recyclability, recovery options, disposal method, and environmental impact.

Tagline: "Waste in. Smart decisions out."

IBM Bob 2.0 Local AI No Cloud Required No API Key Hackathon Project

Slide 2 — Problem Statement

  • Most people don't know how to correctly dispose of waste items
  • Wrong disposal leads to recycling contamination, landfill overload, and environmental harm
  • Existing guidance is text-heavy, hard to find, and not personalised to the actual item
  • WasteWise solves this — upload a photo, get instant expert guidance

Slide 6 — AI Analysis Pipeline (Technical Detail)

Step 1 — Image Description

Image is base64-encoded and sent to moondream via Ollama's streaming chat API with the question: "What object is shown in this image? Describe it in one sentence."

Uses streaming so the connection stays alive during CPU inference (~15s).

Step 2 — Profile Matching

moondream's one-sentence answer is matched against keyword lists in Python. The matched profile contains all 13 structured fields the UI needs instantly — no second AI call.

8 waste categories + default fallback.

Slide 9 — Key Features

🔒 Fully Offline

After setup, WasteWise needs no internet connection. All AI runs locally via Ollama. No data sent to any cloud.

💰 Zero Cost

No API keys. No subscriptions. No credit card. No cloud account. Just Python, Flask, and Ollama.

⚡ Fast Response

15–20 seconds on CPU. moondream is purpose-built for fast image description. Profile matching is instant.

🛡️ Error Handling

Friendly UI messages for: Ollama offline, wrong file type, model not installed, AI timeout, incomplete response.

📱 Responsive UI

Works on mobile (550px breakpoint), tablet, and desktop. Drag-and-drop image upload supported.

🔬 Detailed Analysis

Every scan returns: name, description, confidence, category, materials, recovery options, real-world uses, disposal steps, safety note, and environmental impact.
